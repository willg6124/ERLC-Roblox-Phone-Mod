This manager holds your ER:LC Server Key on this machine only. Player phone overlays connect with the 6-digit codes below and receive filtered live data (911 calls, players, map positions) over WebSocket. The key is never sent to a phone — see docs/SECURITY.md.

How the feed reaches phones

  • Host polls /v2/server (players, vehicles, emergency calls, logs) every few seconds — one consolidated call, rate-limit friendly.
  • Optional: point your in-game Event Webhook at https://<your-host>/webhooks/erlc for instant 911 pushes (Ed25519-verified on the Host).
  • Only whitelisted fields are broadcast — the server Join Key, owner IDs and every credential are stripped first.
  • Admin commands from the Owner phone are re-checked here, then run via POST /v2/server/command.
